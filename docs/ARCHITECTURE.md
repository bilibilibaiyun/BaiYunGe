# 白云歌架构说明

## 目标

白云歌是 Windows 10/11 x64 原生桌面软件。核心链路为：

按住自定义快捷键 -> WASAPI 录音 -> 本地 VAD -> llama-server 离线识别 ->
词典替换 -> 当前焦点输入或复制到剪贴板。

除模型下载外不访问网络，识别音频和文本不离开本机。

## 技术边界

- UI：.NET 8 WPF。
- 音频：NAudio WASAPI 共享模式，统一转换为 16 kHz / 16 bit / mono PCM。
- 唤醒：Win32 WH_KEYBOARD_LL，支持按住模式和点按模式。
- 推理：llama.cpp `llama-server.exe`，只绑定 `127.0.0.1` 和动态端口。
- 输入：优先 SendInput Unicode，输入焦点不可编辑时复制剪贴板。
- 配置、日志、模型和发布目录默认均在 D 盘。

## 核心组件

### AppRuntime

组合根。负责单实例、配置读写、托盘、快捷键、音频、推理服务、状态弹窗和
流水线生命周期。

### KeyboardHotkeyService

维护当前唤醒组合键。过滤注入按键和重复按键，Esc 取消录制。按住模式下抑制唤醒
键以避免焦点跳动；点按模式保留同一唤醒键作为停止信号。

WH_KEYBOARD_LL 回调只做按键过滤和消息投递，不在钩子回调内启动录音、打开窗口
或执行磁盘/网络操作。所有重活由独立消息窗口线程异步处理，避免超过系统钩子
回调时限导致 Windows 静默移除钩子。

按住模式：按下唤醒键开始，松开结束；录音期间忽略该键的重复按下事件。
点按模式：第一次按下开始，录音期间第二次按下唤醒键结束。点按模式下唤醒键的
所有按下事件都被抑制：第一次开始、第二次停止，均不传递给目标程序。

一次会话只接受一个结束信号，按最先到达的以下事件结束：松开、点按模式第二次
按下、自动静音停止、Esc 或 60 秒超时。进入停止态后，其余迟到事件全部忽略，
不得提交重复会话或误开新会话。Esc 取消的会话在任何模式下都不提交识别。
自动静音停止使用“连续静音毫秒数”阈值；提交前的静音检查判断整段录音是否包含
有效语音，两者使用不同的判定层。

### AudioCaptureService

枚举 WASAPI 输入设备，启动/停止共享模式捕获。将任意设备格式流式转换为
16 kHz 单声道 PCM，并报告每帧 RMS 供 VAD 和测试电平条使用。

### LlamaServerManager

启动本地 llama-server，优先级为 Vulkan GPU，失败后自动用 CPU 重试。
维护端口、进程退出、启动超时和重启看门狗。所有 HTTP 调用只允许 loopback。

GPU 回退使用可观测信号：端口未就绪、进程非零退出或健康检查失败。模型启动达到
超时上限时返回明确的超时错误，不再自动触发第二段 CPU 加载等待。CPU 回退成功后
当前进程生命周期内不再频繁重试 GPU。看门狗重启后客户端必须重新获取健康检查地址，
所有在途识别请求进入可重试状态，不能继续使用旧端口。

模型默认不预热，首次实际唤醒时再加载；等待就绪期间状态弹窗显示模型加载状态，
不立即报错。已有配置仍可通过 `WarmupAtStartup` 选择后台预热。

### AsrPipeline

串接一次识别会话。录制结束后先做静音检查，再上传 WAV 到
`/v1/audio/transcriptions`。解析文本、应用词典别名替换，并交给输出服务。
任何异常都通过状态弹窗和日志完整呈现。

### TextOutputService

检测当前焦点是否可接收文本；可编辑时使用 SendInput Unicode 写入，否则复制
到剪贴板。写入过程中不激活本程序窗口。

输入目标在唤醒键按下时锁定。识别完成前若前台窗口已改变，不向新窗口强制写入，
改为复制剪贴板并在状态弹窗说明。

可编辑判定使用 UIA 控件类型、ValuePattern/TextPattern 和常用编辑控件窗口类
的联合策略。中文 IME 场景优先使用直接 Unicode 输入；读回校验判定需要兜底时
使用剪贴板粘贴，并通过 UIA/剪贴板重试处理系统剪贴板忙碌。

直接输入后用 UIA TextPattern 或目标控件类型进行读回校验；无法读回时按目标程序
类型和窗口类判定是否需要剪贴板粘贴兜底。不把“无异常”直接等同于写入成功。

### OverlayWindow

不抢焦点的状态窗口，仅显示聆听、识别、已输入或错误状态。尺寸随文本自适应。
窗口使用 `ShowActivated=false`、`WS_EX_NOACTIVATE`、`WS_EX_TOOLWINDOW`，
不进入任务栏。鼠标命中通过 `WS_EX_TRANSPARENT` 或 `WM_NCHITTEST` 穿透。

### ModelDownloader

只访问模型镜像白名单。支持续传、大小校验、源切换和完成后加载。

模型在下载时使用临时文件名，下载并校验完成后先停止可能占用旧文件的
llama-server，再原子替换，最后按新路径重启。运行中的模型文件不会被下载器直接
覆盖。

## 数据流

```text
快捷键按下
  -> 音频捕获开始
  -> 状态弹窗显示电平与时长
快捷键松开或自动静音停止
  -> 保存 16 kHz mono WAV
  -> VAD 判断
  -> llama-server /v1/audio/transcriptions
  -> 词典替换
  -> SendInput 或剪贴板
  -> 状态弹窗显示结果或错误
```

点按模式在“音频捕获开始”后继续监听同一唤醒键，第二次按下触发停止。

llama-server 响应文本按 `"language XX<asr_text>文本"` 解析，解析失败时记录原始
响应并使用安全的空文本/错误处理，不猜测模型输出。

## 模型约束

- 首选模型：Qwen3-ASR-1.7B 的 GGUF 主模型与 mmproj 投影模型。
- 推理后端：随项目内置的 llama.cpp `llama-server.exe`，Vulkan 与 CPU 双路径。
- 模型下载清单必须同时记录来源、文件名、SHA-256 和期望字节数；下载后逐项校验。
- 模型仓库与许可证信息只写入项目和打包清单，不出现在软件界面。

## 关键约束

1. 不在核心链路中使用浏览器、云转写或外部音频服务。
2. 不让状态弹窗、托盘菜单或设置窗口改变前台焦点；主窗口只响应用户主动打开。
3. 服务器只监听 `127.0.0.1`，不开放局域网端口。
4. 下载器只允许 hf-mirror 与 huggingface 官方镜像，且仅处理已知模型文件。
5. 配置损坏时写入明确错误并重建默认配置，不静默清空用户模型目录。
6. 所有长时间操作使用后台线程/异步执行，UI 线程只接收进度事件。
7. 项目源码、构建工具、模型和安装产物均放在 D 盘。

## 核心行为约束

### 音频静默与隐私

全程不播放提示音、不访问扬声器输出、不修改系统音量或静音状态。录音只使用
WASAPI 输入共享模式。Windows 麦克风权限不足、设备独占或录音流异常时，状态弹窗
显示完整错误，并在用户操作时提供打开系统麦克风设置的入口。

### 输入与权限

程序默认以 `asInvoker` 普通权限运行，不自动请求管理员权限。普通权限进程对
管理员窗口存在 UIPI 限制，分两条路径处理：无法捕获唤醒键时记录原因并告知当前
程序不可用；可以捕获但无法注入文本时降级到剪贴板并记录原因。禁止为了上屏而
启动提权进程或强制切换窗口。

### 界面范围

设置界面只包含功能所需的快捷键、麦克风、词典、模型、输出方式和外观控制。
不出现宣传标语、模型介绍、功能说明装饰或无关链接。外观仅提供日间/夜间模式，
使用标准系统窗口和深/浅实色主题。

界面语言支持简体中文和美国英语。语言保存在用户配置中，设置窗口、托盘菜单、
状态浮窗和首次运行提示会同步切换。安装入口使用 Burn 托管引导程序，在开始安装
前选择中文或英文，再调度对应的本地化 MSI；安装目录、快捷方式和 Windows
安装器维护界面使用所选语言。

### C 盘避让

运行配置、日志、模型、临时音频和 llama-server 工作目录均重定向到 D 盘默认
目录，并支持命令行覆盖。发布采用 .NET 8 自包含，不要求 C 盘安装运行时。
构建环境通过 `DOTNET_CLI_HOME`、`NUGET_PACKAGES` 和本地 SDK 指向 D 盘，避免
NuGet 缓存落到用户目录。

### 离线边界

主程序与 llama-server 都不配置公网地址；模型下载是唯一允许的外网功能。下载器
的 URL、扩展名、文件大小和最终文件名都在白名单与清单中约束，运行期不访问其他
域名。

## 失败与边界行为

- 最大录音时长为 60 秒，超时自动停止，不无限累积音频内存。
- 静音会话不提交识别，状态弹窗显示未检测到语音。
- 默认设备拔除或切换后，录音层抛出可识别错误并刷新设备列表，不静默录制错误设备。
- 剪贴板被其他程序占用时按短间隔重试，仍失败则向用户返回可读错误。
- 退出时使用 Job Object 或等效机制终止 llama-server 子进程，避免残留进程。
- 模型目录、文件大小和模型类型在加载前校验；校验失败不启动服务器。
- 首次运行让用户选择模型目录，默认不写入 C 盘。

## 验证顺序

1. 编译与单元测试。
2. WASAPI 设备枚举和测试录音。
3. 使用已知中文测试音频验证 llama-server 转写。
4. 使用自动管道模拟一次按住、录音、识别和输出。
5. 构建自包含发布包与 Windows 安装器。
6. 验证不抢焦点、静音、无输入框剪贴板、中文 IME、窗口切换、麦克风权限缺失和
   GPU 回退分支。
7. 在 Windows 10 19045 兼容环境和当前开发机分别执行健康检查。
